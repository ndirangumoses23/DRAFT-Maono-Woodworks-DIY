MAONO WOODWORKS — GOOGLE-READY WEBSITE

Files:
- index.html — main website
- maono-woodworks-poster.jpg — poster image
- robots.txt — crawler instructions
- sitemap.xml — sitemap for search engines

IMPORTANT:
The HTML currently uses maonowoodworks.com as the intended domain.
If you choose another domain, replace that domain in index.html, robots.txt and sitemap.xml.

NEXT:
1. Create a GitHub account at https://github.com/
2. Create a new public repository named maono-woodworks.
3. Upload all files in this folder.
4. In the repository, open Settings > Pages.
5. Choose Deploy from a branch, select main and / (root), then Save.
6. GitHub will give you a public website address.
7. Later connect your custom domain under Settings > Pages > Custom domain.
8. Add the live website to Google Search Console and submit /sitemap.xml.

Do not expect instant Google ranking. Indexing and ranking can take time.
